# Demo script (about 2 minutes)

Have the web build open on the title screen. Keep a recorded backup run ready in case the venue network fails.

**0:00 Pitch (15s).** "The Last Drop is a survival game where learning is how you survive. You do not read about waste, you decide what to do with it."

**0:15 Start, the world (15s).** Press Start. The intro plays: you wake in the ruins and need water. Walk out of the shelter.

**0:30 The water (15s).** Inspect the pool. It is contaminated and you cannot drink it. The objective points you to repair the treatment unit, which needs materials.

**0:45 Sorting, the core loop (35s).** Open the scrap pile.
- Deliberately put the **battery in General** and let the consequence land: it costs health, the screen flashes, the lesson explains why, and the same item comes back.
- Then put it in **Hazardous**, and read the real-life tip.
- Sort the rest quickly. Note what is recovered: only reusable materials, never hazards.

**1:20 Repair and reward (15s).** Repair the treatment unit with the recovered scrap, pipe and bottle. Drink clean water. Point out that one repair unlocked another system.

**1:35 The reveal (15s).** Play the recording, open the gate, and read the factory archive: there was no single catastrophe, and the Last Drop is a restoration facility, not magic.

**1:50 Ending (10s).** Choose Preserve or Share. The epilogue changes with how carefully you sorted. Close on: "The world wasn't destroyed in a single day. And it won't be rebuilt in one either."

## Talking points

- Every environmental action solves an immediate problem **and** reveals a real principle.
- The rules are data-driven: new items, lessons and areas are JSON and an ASCII map, not code.
- Tested: unit and integration tests drive a full scripted playthrough, and an automated browser test loads the exported build.
- Plays in the browser with no install.
